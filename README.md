# 🫧 Royal Wash — Servicios Profesionales de Limpieza

Sitio web oficial y plataforma de ventas y cotización para **Royal Wash** (Santa Cruz, Bolivia).
Diseñado bajo el lema: *"Vive feliz, vive limpio"*.

---

## 🛠️ Stack Tecnológico

- **Framework:** React 18 + Vite
- **Lenguaje:** TypeScript
- **Estilos:** Vanilla CSS (CSS Variables + Glassmorphism)
- **Iconografía:** Lucide React
- **Tipografía:** Google Fonts (Outfit & Inter)
- **Despliegue:** Optimizado para Vercel (`vercel.json`)

---

## 📋 Secciones de la Plataforma

1. **Header / Navbar**: Navegación fluida con efecto glassmorphism al hacer scroll y acceso directo a WhatsApp.
2. **Hero Section**: Titular de impacto, sellos de confianza 5 estrellas, llamadas a la acción y visual principal.
3. **Quiénes Somos**: Misión, Visión y pilares de bioseguridad.
4. **¿Por qué elegirnos?**: 5 ventajas competitivas clave del brochure.
5. **Portafolio de 9 Servicios**:
   - Limpieza Corporativa (Oficinas, Edificios)
   - Limpieza Domiciliaria Profesional (Residencial)
   - Limpieza de Sofás y Muebles (Inyección & Extracción)
   - Lavado de Alfombras
   - Limpieza Post-Construcción
   - Lavado de Vehículos a Detalle (Auto Detailing)
   - Lavado y Sanitización de Colchón
   - Limpieza de Vidrios en Altura y Fachadas
   - Lavado y Cuidado de Zapatillas
6. **Equipamiento Industrial**: Showcase de carritos profesionales, equipos de inyección/extracción, pulidoras y aspiradoras de alta potencia.
7. **Contacto & Formulario**: Generador automático de cotizaciones en WhatsApp y datos de contacto oficiales.
8. **Footer**: Enlaces rápidos y derechos reservados.
9. **Botón Flotante de WhatsApp**: Atención al cliente 24/7.

---

## 💻 Ejecución en Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
